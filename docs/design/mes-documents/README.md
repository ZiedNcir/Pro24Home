# Mes documents

Option 2 selected by the user and implemented in the existing native application.

The view focuses on the current missing or rejected document, displays acknowledged submission progress, offers the native file picker or camera, and lists the remaining pieces. Existing server upload, account-scoped phone storage and final pending-account navigation stay in the screen controller. The view also handles upload, rejection, refresh failure and complete states using existing theme tokens and French/English translations.

See the project-root `design-qa.md` for visual evidence, checks and live-backend limits.
